# Инструкция по отладке API

## 🔍 Проблема

После исправлений остаются следующие проблемы:
1. **422 ошибка** при создании ВМ - не хватает полей billing_cycle, storage_category
2. **Не отображаются CPU/RAM** в планах и деталях ВМ
3. **Статусы ВМ** показываются неправильно
4. **Детали ВМ пустые** - CPU 0, RAM 0, Disk 0

## 🛠️ Что было исправлено

### 1. Добавлены обязательные поля для создания ВМ
- `billing_cycle` (по умолчанию: 'monthly')
- `storage_category` (по умолчанию: 'standard')
- `blockstorage_custom_plan.storage` (из disk_size)

### 2. Улучшена нормализация ВМ
Добавлено извлечение данных из множества возможных структур:
```typescript
cpu: apiVM.cpu || apiVM.service_offering?.cpu || apiVM.plan?.cpu || ...
ram: apiVM.ram || apiVM.memory || apiVM.service_offering?.ram || ...
disk: apiVM.disk || apiVM.disk_size || apiVM.volume_size || ...
```

### 3. Изменён минимальный размер диска
Было: 50 ГБ  
Стало: 20 ГБ

### 4. Исправлена навигация
Добавлен `useEffect` который сбрасывает `selectedVM` при смене страницы

## 📊 Отладка через консоль браузера

### Шаг 1: Откройте консоль (F12)

### Шаг 2: Обновите страницу и найдите логи:

```
VM API Response Sample: { ... }
```

Это покажет **реальную структуру** первой ВМ из API. Скопируйте этот JSON и пришлите мне.

### Шаг 3: Откройте детали любой ВМ

Найдите в консоли:
```
VM Detail API Response: { ... }
```

Это покажет полную структуру одной ВМ. Скопируйте и пришлите.

### Шаг 4: Откройте мастер создания ВМ

Найдите в консоли:
```
Plan API Response Sample: { ... }
```

Это покажет структуру тарифного плана. Скопируйте и пришлите.

### Шаг 5: Попробуйте создать ВМ

Найдите в консоли:
```
Creating VM with payload: { ... }
```

Это пока что отправляется на сервер. Если будет ошибка 422, скопируйте полный ответ ошибки.

## 🎯 Что нужно от вас

Пришлите мне следующие данные из консоли браузера:

1. **VM API Response Sample** - структура списка ВМ
2. **VM Detail API Response** - структура деталей одной ВМ
3. **Plan API Response Sample** - структура тарифного плана
4. **Creating VM with payload** - что отправляется при создании
5. **Полный текст ошибки 422** (если будет)

С этими данными я смогу:
- Точно понять какие поля возвращает API
- Правильно маппить CPU/RAM/Disk
- Добавить все обязательные поля для создания
- Исправить нормализацию данных
